# O'zbek Tiliga Tarjima Qilish - Plan

## Loyiha Tavsifi
React + TypeScript klinik boshqaruv tizimi (Cinick). Hozirgi holatda ingliz tilida.

## Maqsad
Barcha UI matnlarni (labels, buttons, headings, placeholders, tooltips, toast xabarlari) o'zbek tiliga tarjima qilish. TypeScript type nomlari va koddagi o'zgaruvchi nomlari ingliz tilida qoladi.

## O'zbek Tilidagi Asosiy Terminologiyalar
- Dashboard = Boshqaruv paneli
- Patient = Bemor
- Doctor = Doktor  
- Appointment = Turni
- Payment = To'lov
- Settings = Sozlamalar
- Search = Qidirish
- Add = Qo'shish
- Edit = Tahrirlash
- Delete = O'chirish
- Save = Saqlash
- Cancel = Bekor qilish
- Login = Kirish
- Register = Ro'yxatdan o'tish
- Logout = Chiqish
